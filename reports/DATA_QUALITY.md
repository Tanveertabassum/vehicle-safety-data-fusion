# Data-quality report

All figures below are generated by `src/06_write_dq_report.py` from the JSON files written by the
pipeline (`reports/dq_metrics.json`, `reports/ingest_summary.json`, `reports/vehicle_table_stats.json`).
They describe the exact raw files listed in the README (SHA-256 verified on ingest:
5/5 files matched).

## 1. What came in

| Source | Format | Rows | Columns | Grain |
|---|---|---|---|---|
| NHTSA complaints 2020-2026 | headerless TAB-delimited text in ZIP, Latin-1, names from data dictionary | 545,345 | 49 | one row per complaint x component |
| NHTSA recall documents 2020-2026 | quoted CSV with header in ZIP | 220,999 | 6 | one row per recall *document* x vehicle |
| EPA fuel-economy table | wide CSV | 48,351 | 84 | one row per tested configuration (model years 1984-2025) |

The three sources describe a vehicle at three different granularities, and none shares an ID with
another. The only common key is the text triple (make, model, model year), which is spelled
differently in every source. That mismatch is the central data-quality problem of this project.

The multi-component structure is not an error, but counting rows instead of complaints would inflate
every complaint statistic by about 1.44x. All counts in this project are distinct complaints.

## 5. Integration: linking complaints and recalls to EPA specifications

| Step | Complaint rows linked (cumulative) |
|---|---|
| Naive exact string join on (make, model, year) | **0.9%** |
| Same, case-insensitive | 76.91% |
| 1. Normalised exact match on EPA base model | 79.93% |
| 2. + match on EPA trim name, or one half of combined names like "Legacy/Outback" | 84.39% |
| 3. + strip repeated make ("MAZDA3" -> "3") | 84.86% |
| 4. + longest EPA base model that prefixes the NHTSA model ("SILVERADO1500" -> "SILVERADO") | 90.06% |
| 5. + NHTSA model prefixes trims of exactly one EPA base model ("GLE450" -> "GLE-Class") | **90.91%** |

Fuzzy rules create false links, so two guards were added after spot checks found real errors:

* **Heavy-duty guard.** EPA does not test heavy-duty pickups and vans. A prefix match onto an EPA pickup or van
  is refused when the remainder is 2500/3500/HD/SD and similar. Blocked, for example: CHEVROLET SILVERADO2500 (1149), GMC SIERRA2500 (691), CHEVROLET SILVERADO3500 (385), GMC SIERRA3500 (346).
* **Different-vehicle guard.** A remainder like EV, LIGHTNING, CONNECT or CITY is refused. Before this guard,
  a petrol F-150 was linked to the electric F-150 Lightning, and a Transit van to the much smaller Transit Connect.

Most frequent fuzzy links, kept after review: CHEVROLET SILVERADO1500 -> SILVERADO (9278); GMC SIERRA1500 -> SIERRA (5552); GMC YUKONXL -> YUKON (1477); FORD MAVERICKHYBRID -> MAVERICK (1306); HYUNDAI SANTAFESPORT -> SANTAFE (971); CHRYSLER PACIFICAPLUGINHYBRID -> PACIFICA (865); FORD F150HYBRID -> F150 (765); FORD ESCAPEHYBRID -> ESCAPE (661).

Still unlinked: 48,883 complaint rows. Of these (categories can overlap), 8,914 are makes EPA does not cover
(largest: FORESTRIVER (932), GRANDDESIGN (722), HARLEYDAVIDSON (534), WINNEBAGO (498), THORMOTORCOACH (445), UNKNOWN (359), CANAM (351), FREIGHTLINER (345): RVs, trailers, motorcycles, heavy trucks), 2,582 were blocked by the heavy-duty guard, and 2,818 have
model year 2025+, where the EPA snapshot is partial or absent. The largest remaining groups:
RAM 2500 (5781), FORD F250 (5083), FORD F350 (2503), RAM 3500 (2292), FORD TRANSIT (684), TOYOTA 4RUNNER (588). The largest of these are heavy-duty trucks (F-250/350, Ram 2500/3500) that EPA does not test.

**Recalls:** only 40.97% of all campaign-vehicle rows link,
because the recall file also covers trucks, buses, trailers and RVs. Restricted to makes EPA covers and model years
before 2025, 79.29% of
11,377 rows link.

## 6. Resulting modelling table

2,487 vehicles (EPA make x base model x model year, 2015-2022), 519 nameplates, 57 makes.
827 (33.25%) had a new vehicle recall campaign filed in 2023 or later.
652 vehicles had no linked complaints in the feature window; these are kept as genuine zeros.
145,221 distinct complaints feed the features. Engine size is missing for
99 vehicles, 88 of which have electric configurations. The model imputes the median and also gets an explicit EV-share feature.

## 7. Known residual issues

* Complaints are unverified consumer reports, and a vehicle's complaint volume also reflects how many were sold.
  Sales data is not public, so EPA configuration count is only a weak proxy.
* Prefix links like "SANTA FE SPORT" -> "SANTA FE" attach a related, not identical, vehicle's specifications.
* The 2025 recall documents look incomplete: 210 campaigns, versus
  563-723 in other years,
  probably because documents lag behind filings. Some 2025 recalls may therefore be missing from the label.
* The model-year/failure-date conflicts (876 rows) were flagged but not corrected.
